# Kadr — автоматическое сохранение скриншотов Win + Shift + S

Kadr сохраняет скриншоты, сделанные через **Win + Shift + S**, в выбранную папку. Выделите область на экране, и снимок сохранится автоматически. Программа продолжает работать в трее после закрытия окна.

[Скачать Kadr 1.1 для Windows](download/Kadr-1.1.exe) · [English README](README.md)

## Возможности

- Автоматическое сохранение скриншотов выделенной области
- Выбор папки и формата PNG или JPG
- Автозапуск вместе с Windows по желанию
- Работа в трее после закрытия окна
- Просмотр последнего снимка и быстрый переход к папке
- Локальное сохранение без загрузки снимков в интернет

## Как пользоваться

1. Скачайте и запустите `Kadr-1.1.exe`.
2. Выберите папку и формат в окне программы.
3. Нажмите **Win + Shift + S** и выделите область. Kadr сохранит снимок.

По умолчанию используется папка `Изображения\Screenshots`. Двойной щелчок по значку в трее открывает окно. Для полного выхода щёлкните по значку правой кнопкой мыши и выберите **Quit**.

Если сочетание Win + Shift + S не открывает системное выделение области, Kadr не сможет сделать снимок: он сохраняет изображения, полученные от Windows.

## Запуск из исходного кода

Нужны Windows и Python 3.10 или новее:

```powershell
py -m pip install -r requirements.txt
py main.py
```

Для сборки `.exe` запустите `build.bat`. Для проверки кода: `py -m unittest discover -s tests`.
